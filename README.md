# Random Task Generator

**Автор:** Чикунова Ангелина
**Дата сдачи** 04.05.2026

## Описание

GUI-приложение для генерации случайных задач с возможностью фильтрации по типу (Учёба, Спорт, Работа) и сохранением истории. Написано на Python с использованием библиотек `tkinter`, `random` и `json`.

### Основные возможности:

- ✅ Генерация случайной задачи из предопределённого списка
- ✅ Фильтрация по типу задачи (Учёба/Спорт/Работа)
- ✅ История всех сгенерированных задач с сохранением в JSON
- ✅ Загрузка истории при запуске
- ✅ Добавление своих задач через интерфейс (с проверкой на пустую строку)
- ✅ Очистка истории
- ✅ Валидация ввода (запрет пустых названий)

## Установка и запуск

### Требования:
- Python 3.7+
- Стандартные библиотеки (tkinter, random, json, os)

### Запуск:
```bash
python random_task_generator.py
